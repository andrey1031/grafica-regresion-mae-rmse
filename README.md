# Laboratorios Interactivos de Machine Learning

Repositorio de visualizaciones interactivas desarrolladas como complemento del curso **Técnicas de ML en Ambientes Big Data para Analítica Predictiva**, de la Universidad de Cundinamarca.

## Objetivo

Facilitar la comprensión de conceptos de Machine Learning mediante experiencias visuales e interactivas que permiten experimentar con datos, métricas de rendimiento y técnicas de reducción dimensional.

## Visualizaciones disponibles

### 1. Regresión lineal, MAE y RMSE
- Gráfico de dispersión con línea de regresión.
- Manipulación de puntos para simular valores atípicos (outliers).
- Actualización dinámica de las métricas MAE y RMSE.

### 2. Laboratorio MAE
- Modificación interactiva de predicciones.
- Visualización de errores absolutos.
- Cálculo dinámico del Error Absoluto Medio (MAE).

### 3. Maldición de la dimensionalidad
- Representación visual de datos en 3D.
- Simulación de la transición hacia una proyección 2D.
- Exploración de diferentes cantidades de atributos.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Canvas API
- GitHub Pages
